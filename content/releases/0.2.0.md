Adds compiled snapshot and result-reporting support. This release introduces opt-in snapshot comparison/update APIs, framework-neutral test result summaries, and deterministic JUnit-style XML serialization. The Progmasoft utilities are built as a static library across the supported build systems; Catch2's existing compatibility engine remains unchanged.
